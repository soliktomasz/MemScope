# UX Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make MemScope's investigation tables keyboard-friendly, sortable, resizable, copyable, consistently formatted, and clear during loading or empty states.

**Architecture:** Keep the current MVVM/navigation structure. Add small formatting and clipboard boundaries, expose commands and cancellation from the owning view models, and compose the behavior with native Avalonia controls and shared FluentTheme resources.

**Tech Stack:** .NET 10, C#, Avalonia 12.1.1, xunit 2.9.3

**Spec:** `docs/superpowers/specs/2026-09-01-ux-polish-design.md`

## Global Constraints

- Preserve automatic light/dark FluentTheme, the blue accent, 4 px radius, current navigation, and virtualization.
- Keep expensive work off the UI thread and reuse existing cancellation/version guards.
- Use current-culture number formatting and binary byte units.
- Add no web UI packages or decorative animation.
